# 整團 NS 軸

這裡保存 RL 核准後、後續實戰要使用的整團四補、五補或六補治療排招。個人 NS 只另維護補薩與龍補兩份通用版；其他補師直接使用整團 NS。NS 只放治療技能，戰士、DK、DH 團隊生存招與個減／糖紅另看 [RL 整團時間軸](../整團時間軸/README.md)。

> 團隊規則：30 人版本直接以六補為預設，五補檔只保留作臨時缺席備案；新增第六補不移動原五補落點。H1–H3 保留一團／二團分團版本；H4 起維護「本團」完整補軸。本團五補為 Arielle／菈菈跳來跳去／呆小鄭／豆腐天尊／Raitoningu；需要六補時加入血薩靈。

後續檔案依照以下順序整理：

```text
整團NS軸/
├─ 一團/（H1–H3）
│  ├─ N/
│  └─ H/
├─ 二團/（H1–H3）
│  ├─ N/
│  └─ H/
└─ 本團/（H4 起；保留既有 H3 歷史檔）
   ├─ H/
   └─ M/
```

每個難度底下以副本與王序命名，例如：

- `浪縛單王.txt`
- `劇毒1王.txt`
- `劇毒2王.txt`

每份檔案保留完整 NSRT 標頭、名單與所有補師的排招，可以直接複製匯入；不混入戰士、DK、DH 或純文字自保提醒。RL 軸首次核准後建立整團 NS；補薩、龍補另同步通用個人 NS。後續實戰微調不需回寫 RL 軸。
