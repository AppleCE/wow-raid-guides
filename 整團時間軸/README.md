## 閱讀方式

- RL 軸可同時放五補、戰士、DK、DH、個減與糖紅；首次核准後，才把治療部分產生為實戰 NS。
- RL 軸標示 `draft` 時仍可能修改；不得把尚未核准的草稿自動覆蓋實戰 NS。
- 後續實戰微調 NS 時，只同步整團 NS、個人 NS 與相關補師攻略；不需回寫這份 RL 審核軸。
- `王的技能／傷害` 是這一格為什麼要用資源。
- `本團補招` 是回復血量的技能；不等同防止秒殺。
- `團減／個減` 才是大傷害前的生存安排。
- `補師盯／外部` 只代表治療分工，不要求被點者交個減；只有明寫 `指定自保` 才需要交。
- 全團統一個減一旦排定，前 120 秒不再依賴同一批人的兩分鐘自保；短 CD、多充能或第二個獨立個減必須另行確認。
- 自保、糖、紅分開計算；120 秒只管兩分鐘個減。糖與紅是每名玩家各自每場一次；隨機點名的多個波次可標 `被點：糖／紅`，同一人再次中招則不能重複使用已交過的那一種。
- 聖騎聖盾術、獵人巨龜守護、盜賊暗影披風、法師寒冰屏障預設仍算個減；只有該王戰術或相同戰術 WCL 明確要求保留特定用途時，才從一般自保池扣除並另列戰術用途。
- 純機制失敗不靠追加補招處理；表內只標正常打法仍存在的治療缺口。
