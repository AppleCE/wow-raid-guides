# WoW 團本治療攻略

公開保存與更新 World of Warcraft 團本治療攻略、補招與實戰注意事項。

## 補職攻略

目前先公開四個補職的簡略版；詳細版會另外寫完整戰鬥流程、技能波次、個減與外部防禦建議。每份攻略旁都有可直接複製的個人 NS 軸。

- 龍補：[簡略版](補職攻略/龍補/H攻略_簡略.md)｜[H3–H7 詳細版](補職攻略/龍補/H攻略_詳細.md)｜[NS 軸](補職攻略/龍補/NS軸/H/README.md)
- 補薩：[簡略版](補職攻略/補薩/H攻略_簡略.md)｜[H3–H7 詳細版](補職攻略/補薩/H攻略_詳細.md)｜[NS 軸](補職攻略/補薩/NS軸/H/README.md)
- 補聖：[簡略版](補職攻略/補聖/H攻略_簡略.md)｜[H3–H6 詳細版](補職攻略/補聖/H攻略_詳細.md)｜[NS 軸](補職攻略/補聖/NS軸/H/README.md)
- 神牧：[簡略版](補職攻略/神牧/H攻略_簡略.md)｜[H3–H6 詳細版](補職攻略/神牧/H攻略_詳細.md)｜[NS 軸](補職攻略/神牧/NS軸/H/README.md)

完整目標固定為浪縛單王、劇毒 H1–H8 與 M1–M8，內容隨實際進度逐王增加。目前龍補已整理到 H7，H8 待補；M 會在有對應進度與可靠紀錄後放回相同補職與首領資料夾，不另開「前幾王」臨時系列。

補職攻略與補職資料夾內的個人 NS 軸採通用專精版本，匯入時把通用 `tag` 換成自己的角色名；因此第三團龍補 `龍餘` 與補薩 `小印` 可以直接共用。整團資料夾內的團隊 NS 軸才保留實際出團角色名與彼此錯開關係。
