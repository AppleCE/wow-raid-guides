# 補聖 H攻略（詳細）

> 最後更新：2026-08-25（Asia/Taipei）

適用角色：本團 `Arielle`。目前完成浪縛單王與 H1–H7，H8 待補。

## 共通判斷

- `精通光環` 是傷前減傷；要在致命傷害落下前開，不是全團掉血後補按。
- `犧牲祝福` 只給「單點＋下一個大傷」的重疊目標。一般點名由你與神牧一起顧，不固定浪費外部。
- 分場王只看自己半場；不要把另一側的補招當作自己的覆蓋。

## H5 Sszorak

治療模型：[劇毒 5 王 H 治療分析](../../首領/劇毒5王_Sszorak/H/治療分析.md)

### 先記住你的工作

- 你與呆小鄭共同優先顧致殘劈砍目標，尤其是流血再疊毒素湧流或暴怒橫風的人。
- 菈菈主顧兩名放球者，豆腐天尊負責必要的外場備援；你留在能同時顧分攤組與主團的位置。
- 犧牲祝福留給三層 DOT 下已低血、下一跳前補不滿的人，不固定交給每次點名。
- 淨化術可解暴風；單人反應驅散，優先同時帶流血／放球的人。

### 你要辨識的技能

| 技能 | ID | 你要做什麼 |
| --- | ---: | --- |
| **毒素湧流** | `1305963`／`1312156`／`1306120` | 每次兩人；留主團幫看其中帶流血或即將低血者。 |
| **暴怒橫風** | `1312219`／`1285616` | 末段會與湧流、流血重疊；重疊前先補滿並準備直補／外部。 |
| **肢解／致殘劈砍** | `1285999`／`1285998` | 分攤後留下流血；你與神牧共同優先顧。 |
| **暴風** | `1287083` | 可用淨化術處理；優先雙 debuff 目標。 |
| **黏稠囊腫** | `1287205` | 大風依序撞四顆，每顆各有團傷與擊退。 |

### 戰鬥循環

每個大循環先是肢解正面分攤並留下致殘劈砍，接第一次毒素湧流兩人；湧流末段接暴怒橫風。王再做一次坦克連招、第二次湧流兩人與第二次橫風，兩輪共留下四顆囊腫。大風階段依序撞四顆囊腫，每顆都造成一次團傷與擊退；處理完回到主階段。整套重複三次，第三次大風後收尾。

### 完整時間軸

| 時間 | 王的流程 | Arielle 要注意 |
| ---: | --- | --- |
| `00:00–00:47` | 肢解 → 第一次湧流 → 橫風 | 分攤後高亮致殘劈砍；橫風前補滿帶流血者。 |
| `01:25–01:45` | 第二次湧流 → 橫風 | `01:37–01:40` 三層 DOT，與呆小鄭共同直補；危急者才給犧牲祝福。 |
| `01:51–02:22` | 第一個大風／四顆囊腫 | 四次撞球逐波回穩；`01:02` 的復仇之怒延續前段資源，不為撞球失誤追加固定外部。 |
| `02:51–03:10` | 第二循環第一次湧流 → 橫風 | `03:03` 復仇之怒；`03:02–03:05` 再次共同顧三層 DOT。 |
| `03:43–04:40` | 第二次湧流、橫風 → 四顆囊腫 | `04:21` 精通光環在囊腫傷害前開，逐波補回。 |
| `05:04–05:35` | 第三循環第一次湧流 → 橫風 | `05:04` 復仇之怒；帶流血又被點者仍是第一優先。 |
| `06:01–收尾` | 最後湧流、橫風 → 四顆囊腫 | `06:04` 聖佑術；最後四次撞球不再保資源。 |

### 目標優先順序

1. 致殘劈砍再疊毒素湧流／暴怒橫風的人。
2. 三層 DOT 下已低血、需要犧牲祝福的人。
3. 中暴風又帶其他 debuff 的人。
4. 分攤組與正常團血。

## H6 The Twin Fangs

治療模型：[劇毒 6 王 H 治療分析](../../首領/劇毒6王_The_Twin_Fangs/H/治療分析.md)

### 先記住你的工作

- 全補共同看盤卷膿液；你與呆小鄭優先直接點補被點者，持續到緊接的攪動深淵結束。
- 被點者又要進盛宴／腐蝕球時仍維持優先；高毒層且低血才升級犧牲祝福。
- 精通光環在攪動深淵傷害落下前開。盛宴依固定三組，不能因低血臨時換組。

### 你要辨識的技能

| 技能 | ID | 你要做什麼 |
| --- | ---: | --- |
| **永恆毒液／有毒氣體** | `1290480`／`1294976` | 背景壓力逐輪增加；後段單點與團血都要提早處理。 |
| **盤卷膿液** | `1290814`／`1290809`／`1290878` | 約 7–8 人分散放水；你與神牧優先直補低血者。 |
| **攪動深淵** | `1290956`／`1292806` | 放水後約 8 秒團傷並躲波；精通光環對齊第一、第四輪。 |
| **貪噬盛宴** | `1290516`／`1290662` | 固定三組依序分攤，進圈前補滿。 |
| **腐蝕球** | `1289201`／`1290338` | 一人一球；點名者同時低血時繼續照顧。 |
| **血雨** | `1306876`／`1313533` | 第六輪後長段團傷，剩餘資源交完。 |

### 戰鬥循環

六輪皆依序為背景毒傷、盤卷膿液分散放水、攪動深淵移動團傷、三組貪噬盛宴，輪次間穿插腐蝕球。吃過盛宴的組有易傷不能換進下一圈；後段永恆毒液層數提高。第六輪盛宴後接血雨收尾。

| `00:49–01:11` | 第一輪盤卷膿液 → 深淵 → 盛宴 | 直補點名者；`00:53` 精通光環在深淵前開。 |
| `01:57–02:19` | 第二輪 | `01:57` 聖佑術、`01:58` 復仇之怒；點名者進盛宴時繼續顧。 |
| `03:39–04:01` | 第三輪 | 盤卷膿液低血者先補滿；腐蝕球前維持安全血線。 |
| `04:23–05:07` | 第三輪後腐蝕球 → 第四輪 | `04:23` 復仇之怒、`04:47` 聖佑術、`04:50` 精通光環。 |
| `06:26–06:50` | 第五輪 | `06:26` 復仇之怒；高毒層低血又要盛宴者才給外部。 |
| `07:36–07:58` | 第六輪 | `07:36` 聖佑術；`07:54` 低血用紅水。 |
| `08:07–08:22` | 血雨 | 低血用治療石，剩餘直補與資源全部交完。 |

### 目標優先順序

1. 盤卷膿液低血者，尤其正在移動的人。
2. 盤卷膿液未結束又要進盛宴／腐蝕球的人。
3. 當輪即將進盛宴的固定組。
4. 高毒層下的正常團血。

## H7 The Coiled Altar

治療模型：[劇毒 7 王 H 治療分析](../../首領/劇毒7王_The_Coiled_Altar/H/治療分析.md)

### 先記住你的工作

- 你是揮發毒液運球者的直補主責；菈菈先預鋪，運球撞上其他大傷時豆腐天尊備援。
- P2 與呆小鄭共同優先顧處斬、幽暗炸彈與墓縛；P2.5 四批碎片按四波處理。
- 精通光環在毒液爆裂或毒暗大傷落下前開，不在掉血後補按。
- 犧牲祝福只給運球／墓縛又疊大傷且已低血的人。

### 你要辨識的技能

| 技能 | ID | 你要做什麼 |
| --- | ---: | --- |
| **聚合毒液** | `1282408` | P1／P3 毒球脈衝，準備團血。 |
| **揮發毒液** | `1282419`／`1282288` | 固定運球者持續掉血；你主責直補到結束。 |
| **毒液爆裂** | `1299838` | 坦克消球後 10 秒可堆疊團傷；精通光環要在傷害前開。 |
| **處斬／冷酷處斬** | `1283594`／`1299296` | 固定組分攤，與神牧共同顧。 |
| **恐怖威壓** | `1288635` | P2 持續團傷。 |
| **幽暗炸彈／墓縛** | `1310883`／`1297906`、`1308330` | 炸彈後目標撿三片靈魂；與神牧共同直補。 |
| **精魂抹除** | `1287722` | P2.5 四批團傷。 |
| **盤繞祭壇褻瀆** | `1298594` | P3 吸收盾與安全地板變化。 |

### 戰鬥循環

P1 固定運球者取得揮發毒液送球，坦克消球後觸發毒液爆裂，期間穿插安全地板與處斬。P2 改成恐怖威壓、永恆夜幕吸收盾與三輪幽暗炸彈／墓縛；墓縛者要撿三片靈魂。P2.5 是精魂抹除四批碎片。P3 把毒球、運球、毒液爆裂、處斬與暗影吸收／點名合併。
