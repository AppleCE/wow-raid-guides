# 劇毒 7 王 H：The Coiled Altar 完整攻略

> 最後更新：2026-08-25（Asia/Taipei）
>
> 治療缺口、單點責任與自保波次另見：[治療分析](治療分析.md)。本頁使用 Google 文件指定的 9:11 H 軸解釋完整流程。

## 先看懂整場

這場依序打祖爾加、妖術領主瑪拉克雷斯，接著經過靈魂綁定轉場，最後同時擊殺兩人：

```text
P1 毒液與運球 → P2 恐懼與靈魂機制
→ P2.5 擋靈魂碎片 → P3 毒液＋恐懼同時回歸
```

英雄難度新增四個核心限制：

- 毒球被摧毀後，**毒液破裂**變成可疊加的十秒全團 DOT。
- 斬首分攤者會獲得 500% 易傷，必須使用兩組輪流分攤。
- P2 與 P3 會出現惡毒盤蛇者，恐懼讀條必須打斷。
- 轉 P2 時殘留毒球會一起被清掉；留下幾顆球會直接改變轉階段團傷。

外部圖解：[Method：全場標記與集合位置](https://www.method.gg/images/uploads/guides/2208565-the-coiled-altar-heroic-marker-positioning.jpg)。圖片只用來理解場地與機制位置；本團的標記、運球數量、分攤組及技能秒數仍以既定戰術與 WCL 軸為準。

## P1：毒液階段

### 盤蛇祭壇之牙

**盤蛇祭壇之牙**（`1282512`）持續造成全團傷害，並在場地形成兩塊毒液地板。每次施放後地板範圍更大，安全區會逐輪改變；全團打完一輪要跟著既定方向移動。

### 聚合毒液、運球與切砍

劇毒洪流會在場上生成 **聚合毒液**（`1282403／1282408`）。每顆球存在時都會每兩秒脈衝全團；玩家踩球後取得五秒 **不穩定的劇毒**（`1282419`），可以把球運到坦克正面預定位置。

坦克用切砍正面摧毀球：

- 球要先被運成一小群，讓一次正面清掉計畫數量。
- 每顆球被摧毀都觸發 **毒液破裂**（`1299838`），持續十秒且可疊加。
- 一次劈太多會讓 DOT 疊太高；留下太多到轉階段又會一起爆。
- 運球者五秒內本身也持續受傷，不能帶球穿過大團。

外部圖解：[Method：聚合毒液集中與坦克正面消球](https://www.method.gg/images/uploads/guides/2208568-the-coiled-altar-heroic-coalesced-venom-orbs.jpg)。

### 斬首與旋轉斧

**斬首**（`1283485／1283594`）點一名玩家，至少五人進圈分攤；實戰通常使用兩組六人交替。斧頭落地後還會向外爆炸，分攤完要立刻離開。

英雄難度分攤者有長時間 500% 易傷，同一組不能連吃。若少於五人，技能會轉成全團處決。場上的旋轉斧會持續移動，碰到屬可避免傷害。

外部圖解：[Method：斬首分攤位置](https://www.method.gg/images/uploads/guides/2208560-the-coiled-altar-heroic-guillotine-group-soak-positioning.jpg)。

### 毒牙驅散

隨機玩家會中可驅散的毒 DOT。補師按名單依序驅散，不要為了搶驅散打亂運球者、斬首組與毒液破裂的主要治療節奏。

## P2：暗影階段

祖爾加倒下後，瑪拉克雷斯進場；此階段團隊大致集合在首領後方，方便處理恐懼進軍與靈魂怪。

### 恐懼進軍與恐懼化身

**恐懼進軍**（`1285643`）控制數名玩家往最近的場邊走。全團先集合，立刻打破他們身上的吸收盾，不能讓人走下平台。

解除後會生成 **恐懼化身**（`1285844`）：

- 化身會追固定目標；目標看著它時會停止，轉身時才會前進。
- 把數隻化身帶成鬆散一群，讓坦克的 **靈魂切離**正面一起清掉。
- 被追上會再次恐懼進軍；這是機制失敗，不靠補招硬扛。

外部圖解：[Method：恐懼化身集合方式](https://www.method.gg/images/uploads/guides/2208562-the-coiled-altar-heroic-manifestation-of-dread-ghosts.jpg)。

### 靈魂切離與靈魂碎片

**靈魂切離**（`1286620`）是朝坦克的暗影正面，會摧毀恐懼化身。坦克吃到後獲得墓縛類效果，必須在時限內踩回自己的三片 **靈魂碎片**（`1286839`）；每踩一片都有個人傷害。

非坦克不要站正面。坦克連續踩片時，補師要維持安全血線，但漏片超時屬機制死亡。

外部圖解：[Method：坦克用靈魂切離清除化身](https://www.method.gg/images/uploads/guides/2208561-the-coiled-altar-heroic-soul-sever-on-ghosts.jpg)。

### 永夜無光

**永夜無光**（`1286918`）開始後，瑪拉克雷斯獲得護盾並讀致命技能；場上同時出圈，全團每兩秒疊加 **窒息黑暗**（`1286947`）治療吸收。

全團躲圈、集火打破護盾，再中斷讀條。護盾破得越慢，治療吸收越厚；這段看起來血量未必下降很多，但補師其實要先打穿吸收。

### 靈魂奸笑與幽暗炸彈

英雄難度的 **靈魂奸笑**（`1286441`）召喚惡毒盤蛇者。小怪會反覆讀全團恐懼，必須打斷並優先擊殺；每次被打斷後會移動，遠程要接後續斷法。

**幽暗炸彈**（`1310881／1310883`）點數名玩家，五秒後在 15 碼爆炸並產生靈魂碎片。被點者出大團、爆炸後立刻踩回自己的碎片；不要炸到其他人。

## P2.5：靈魂綁定

瑪拉克雷斯倒下後開始 **靈魂綁定**（`1304032`），持續治療祖爾加並使他受到的傷害提高 100%。這是嗜血與主要輸出窗口。

場邊會不斷有靈魂碎片往祖爾加移動：

- 玩家用身體擋下碎片，觸發 **靈魂抹煞**（`1287722`）全團傷害。
- 碎片若碰到祖爾加，會治療首領。
- 不要所有人同時亂踩；依 RL 分批攔截，讓每波團傷之間有回補時間。

外部圖解：[Method：轉場攔截瑪拉克雷斯碎片](https://www.method.gg/images/uploads/guides/2208569-the-coiled-altar-heroic-intermission-fragments-of-malacrass.jpg)。

指定 8:47 場約 `04:55–05:27` 連續處理四批，正式拓荒仍以本團踩片節奏為準。

## P3：毒暗同時回歸

轉場結束後兩名首領同時作戰。兩人血量不共享，任一人先死，另一人會提高 500% 傷害與攻速，所以必須一起壓血。

P3 會同時出現：

- 聚合毒液、運球與毒液破裂。
- 恐懼進軍、恐懼化身與盤蛇者斷法。
- 幽暗炸彈與靈魂碎片。
- 斬首升級成 **恐怖斬首**（`1299266／1299296`），分攤者另帶治療吸收。
- **盤蛇祭壇褻瀆**（`1298594`）給全團治療吸收並改變安全地板。
- 坦克用強化正面同時清理毒球與恐懼化身。

本階段不是分開做 P1、P2，而是把兩套機制疊在一起。處理優先順序是：先完成即將致死的分攤／心控／斷法，再運球與清怪；補師則把毒液破裂的十秒團傷與被點者的碎片生命週期一起看。

## 9:11 本團指定戰術時間軸

首領技能秒數以 Google 文件指定的 [WCL `VQvzDYJ7Bjpqdm2H` fight 35](https://tw.warcraftlogs.com/reports/VQvzDYJ7Bjpqdm2H?fight=35&type=summary) 為準；[WCL `fCZNKw2dBkMQVt6R` fight 50](https://www.warcraftlogs.com/reports/fCZNKw2dBkMQVt6R?fight=50&type=summary) 只用作五補協調骨架。

| 時間 | 流程 |
| ---: | --- |
| `00:00–02:52` | P1：祭壇之牙、反覆運球／劈球與斬首；`00:23`、`01:48` 指定大消球，最後依現場控好殘球 |
| `03:12–04:57` | P2：幽暗炸彈、控心、ADD、斬首與永恆夜幕吸收盾交錯 |
| `04:57–05:40` | P2.5：靈魂綁定，分批攔截靈魂碎片並準備進 P3 |
| `05:40–06:19` | P3 起手：幽暗炸彈、分傷、毒液爆裂與吸收盾開始重疊 |
| `06:48–07:32` | 中段：毒液爆裂／斬首、控心、團傷與幽暗炸彈連續出現 |
| `07:59–09:10` | 後段：吸收盾、毒液爆裂、控心、炸彈與分傷密集收尾 |

本團只固定 `00:23`、`01:48` 兩次大消球；其他消球數與剩球依現場調整。`01:48` 預排全團個人減傷，若實際消球較少則由 RL 順延到下一次較大的消球。

## 第一次進場只記六件事

1. P1 運球按固定名單；坦克按計畫數量劈球。
2. 斬首兩組輪流，分攤後立刻離開斧頭爆炸範圍。
3. 恐懼進軍先集合破盾；恐懼化身用視線停住並帶給坦克正面。
4. 永夜無光先打盾、再斷法；補師要處理全團治療吸收。
5. P2.5 靈魂碎片分批踩，不要同時引爆。
6. P3 兩王一起壓血；斷法、心控與分攤永遠先於貪傷害。
