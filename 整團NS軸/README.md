# 整團 NS 軸

這裡保存整團五補或六補的完整排招；各補職只看自己開招的版本，仍放在各補職的 `NS軸` 資料夾。

後續檔案依照以下順序整理：

```text
整團NS軸/
├─ 一團/
│  ├─ N/
│  └─ H/
├─ 二團/
│  ├─ N/
│  └─ H/
└─ 本尊團/
   ├─ H/
   └─ M/
```

每個難度底下以副本與王序命名，例如：

- `浪縛單王.txt`
- `劇毒1王.txt`
- `劇毒2王.txt`

每份檔案保留完整 NSRT 標頭、名單與所有補師的排招，可以直接複製匯入。
