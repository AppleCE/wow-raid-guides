## 分工

盤卷膿液一次會點多人，這王不硬切第一批、第二批；全補共同看點名與團血，以下只分每人的優先工作。

| 補師 | 優先工作 |
| --- | --- |
| Arielle | 優先點補盤卷膿液 `1290814` 被點者。 |
| 呆小鄭 | 與 Arielle 一起看盤卷膿液被點者。 |
| 菈菈跳來跳去 | 點名前預鋪被點者，並維持主團 HOT。 |
| 豆腐天尊 | 幫看盤卷膿液被點者，移動段優先補位。 |
| Raitoningu | 優先維持主團與移動中的團血。 |

被點者的照顧持續到盤卷膿液結束並接上攪動深淵；其他補師看到危險血線仍直接幫補，不等主顧喊缺口。重疊圈、吃毒浪、漏球與錯盛宴組先修機制。

## 特殊提示

長場六輪盤卷膿液約在 `00:48`、`01:56`、`03:37`、`04:45`、`06:27`、`07:35` 開始。每輪提前 2 秒找被點者；不要只看第一下，照顧持續到最後幾跳接攪動深淵。
