# WoW 團本治療攻略

這是一套給團隊實戰使用的治療資料：先讀首領頁理解「為什麼這裡危險」，再看自己的補職頁，最後把 NS 軸匯入遊戲。

版本：正式服 `12.1.0`。最後整理：`2026-08-29（Asia/Taipei）`。

## 從這裡開始

1. [完整首領攻略](#完整首領攻略)：第一次進場先看懂完整機制、階段循環與長場波次。
2. [每王治療分析](#每王治療分析)：正常治療缺口、機制死亡、團減與單點責任。
3. [補職攻略](補職攻略/README.md)：先選 [H](補職攻略/H/README.md) 或 [M](補職攻略/M/README.md)；分開查看角色責任、主責、備援與交接條件。
4. [整團 NS 軸](整團NS軸/README.md)：實際角色的四補／五補／六補接力；目前可直接查看 [H8 六補軸](整團NS軸/本團/H/劇毒8王%286補%29.txt)與 [M3 四補軸](整團NS軸/本團/M/劇毒3王.txt)。
5. 個人 NS 軸：H 只維護[補薩](補職攻略/H/補薩/NS軸/H/README.md)與[龍補](補職攻略/H/龍補/NS軸/H/README.md)兩份通用版；M 以固定四補角色攻略與本團整團 NS 為準。
6. [團隊補招與減傷時間軸](整團時間軸/README.md)：按 H／M 與首領查詢王技能、五／六補、團減及個減。
7. [盤蛇島 22 個寶藏攻略](世界內容/盤蛇島/22個寶藏攻略.md)：依建議移動路線排列，包含完整解謎步驟與可直接貼入遊戲的座標。
8. [團本 FPS 畫面建議設定](UI設定/團本FPS畫面建議設定.md)：可直接照表調整 WoW 原生團本畫面設定。
9. [拓荒統計](拓荒統計/README.md)：世界前 50／100／200／400／500 公會各王傳奇拓荒把數，不定期更新；[互動版](https://applece.github.io/wow-raid-guides/%E6%8B%93%E8%8D%92%E7%B5%B1%E8%A8%88/)可查逐公會把數。
