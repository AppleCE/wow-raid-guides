## 讀法

- 排名分段依 raider.io 世界進度排名切，區間互斥（前 50、51–100、101–200、201–400、401–500）。
- 「已殺公會」的範圍：M1–M8 是本頁世界前 500 公會中的已殺數；浪縛單王是 raider.io 該王世界榜的總擊殺公會數。括號內樣本數才是有公開把數、實際納入平均的公會數。
- 裝等＝首殺陣容的平均裝等。M1–M8 取 WCL 進度榜；浪縛優先取 raider.io Live Tracking 首殺 pull 的 `itemLevelEquippedAvg`，沒有時改讀公開 WCL 首殺 fight 的 `averageItemLevel`。未公開陣容的公會不列入裝等樣本。
- 首殺先後分組依各王的實際擊殺時間排序；「最早 1–25 個首殺公會」就是最早打掉該王的 25 個公會，與公會整體世界排名無關。浪縛單王的時間取 raider.io 排行資料 `encountersDefeated.firstDefeated`。
- 把數＝擊殺前所有 `ENCOUNTER_START` 次數；擊殺沒有上傳 log 的公會 pull 為 0，已排除。
- 「還在打」＝前 500 內尚未擊殺但已開始拉的公會，列平均把數與最佳％中位數。
- WCL 進度 API 只在競速期間開放；若某天回空，本頁保留前一天內容。
- 把數來源：M1–M8 以 WCL 進度榜為主，WCL 對不到或擊殺沒上傳 WCL 的公會用 raider.io Live Tracking（公會需以 Raider.IO App 上傳）補；浪縛單王不在 WCL 進度榜內，名單取 raider.io the-tidebound-grotto 傳奇榜，把數優先用 Live Tracking、沒有的再掃該公會公開 WCL 報告。兩邊都沒有的公會不計。
