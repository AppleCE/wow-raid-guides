## H5 Sszorak

[補師分配](../補師分配/H5_Sszorak.md)｜[治療攻略](../../../首領/劇毒5王_Sszorak/H/治療分析.md)

### 先記住你的工作

- 你是六次**毒素湧流／放球**兩名目標的主責，從點名出現一路照顧到 debuff 結束。
- 自己被點、被迫留在另一側、超出射程，或兩名目標分開時，由豆腐天尊接其中一人。
- 點名前先預鋪；移動時保持兩名放球者都在可治療範圍，不需要跨場追已交接的目標。
- 所有補師仍要看全團；這項硬分工只因放球者會離團、分方向並可能超出射程。

| **毒素湧流** | 目標 `1305963`、持續傷害 `1312156`、結束爆炸 `1306120` | 每次兩人。提前預鋪並跟到結束；兩人分線時交一人給豆腐天尊。 |
| **暴怒橫風** | 持續傷害 `1312219`、到期爆炸 `1285616` | 會疊到毒素湧流末段；維持放球者 HOT，爆炸前確保安全血線。 |

| **暴風** | `1287083` | 可避免的毒。中招者又帶放球或流血時提高優先級。 |
| **黏稠囊腫** | `1287205` | 大風依序處理四顆；每顆都有團傷與擊退，擊退後重新站好再接下一顆。 |

### 戰鬥循環

整場重複三次大循環：坦克先處理肢解與正面分攤，分攤者留下致殘劈砍；接著第一次毒素湧流點兩人，約 10 秒後爆炸並各留一顆囊腫。毒素湧流末段會接暴怒橫風，橫風到期爆炸、擊飛並進入對撞。之後王再做坦克連招、第二次毒素湧流兩人與第二次橫風，場上共留下四顆囊腫。

大風階段會依序處理四顆囊腫；每次撞球都各自造成一波團傷與擊退，因此是「撞一顆、回穩移動、再撞下一顆」共四次。四顆結束後回到主階段；第三次大風後收尾。

2. 同時帶致殘劈砍＋毒素湧流／暴怒橫風的人。
3. 中暴風又疊其他傷害的人。
4. 四次撞球後的正常團血。

## H6 The Twin Fangs

[補師分配](../補師分配/H6_The_Twin_Fangs.md)｜[治療攻略](../../../首領/劇毒6王_The_Twin_Fangs/H/治療分析.md)

### 先記住你的工作

- 六輪盤卷膿液出現前，優先替實際被點者預鋪；HOT 維持到盤卷膿液與緊接的攪動深淵結束。
- Arielle／呆小鄭優先直接點補，豆腐天尊幫看移動段；你在預鋪點名的同時維持主團 HOT。
- 盛宴依固定三組分攤，前一組帶易傷不能換組；進圈前先把自己組與低血者補穩。
- 腐蝕球階段一人一球，保持自己責任區的治療距離，不為追單人破壞站位。

### 你要辨識的技能

| 技能 | ID | 你要做什麼 |
| --- | ---: | --- |
| **永恆毒液** | `1290480` | 全場背景壓力會逐輪升高，後段預鋪不能只放在點名者。 |
| **有毒氣體** | `1294976` | 與其他技能疊加形成團血缺口，維持全團 HOT。 |
| **盤卷膿液** | 目標 `1290814`、施放 `1290809`、傷害 `1290878` | 一次約 7–8 人分散放水；點名前預鋪，移動時繼續照顧。 |
| **攪動深淵** | 施放 `1290956`、傷害 `1292806` | 放水後約 8 秒連續團傷並躲波；用移動治療維持 HOT。 |

| **腐蝕球** | `1289201`／`1290338` | 一人一球；進球前補穩，分散後以既有 HOT 支撐。 |
| **血雨** | `1306876`／`1313533` | 第六輪盛宴後的最後長段團傷，不再保補招。 |

### 戰鬥循環

每輪先承受永恆毒液與有毒氣體的背景傷害，接著盤卷膿液點約 7–8 人。被點者分散到場邊放下水池，王立刻接攪動深淵，團隊一邊移動躲波、一邊承受約 8 秒團傷。之後是貪噬盛宴，固定三組依序進圈分攤；吃過的組有易傷，不能臨時換到下一圈。輪次之間穿插腐蝕球，一人處理一顆。

這套流程共六輪，背景毒傷會愈來愈重；第六輪盛宴結束後進血雨收尾。

3. 當輪即將進盛宴的固定組。
4. 高層永恆毒液下的正常團血。

## H7 The Coiled Altar

[補師分配](../補師分配/H7_The_Coiled_Altar.md)｜[治療攻略](../../../首領/劇毒7王_The_Coiled_Altar/H/治療分析.md)

### 先記住你的工作

- 固定運球者拿到揮發毒液前先預鋪；Arielle 主顧直補、豆腐天尊高壓時備援，你維持 HOT 後回頭顧主團。
- P2 不需要追運球者；改看斬擊、幽暗炸彈、墓縛與全團永恆夜幕吸收盾。
- P2.5 是四批靈魂碎片，每批都有團傷；先鋪好再跟團移動。
- P3 毒與暗影機制同時回歸，固定運球者出發前要有完整預鋪。

### 你要辨識的技能

| 技能 | ID | 你要做什麼 |
| --- | ---: | --- |
| **聚合毒液** | `1282408` | P1／P3 毒球持續脈衝；維持全團 HOT。 |
| **揮發毒液** | 光環 `1282419`、傷害 `1282288` | 固定運球者約 5 秒持續掉血；出發前預鋪，不跨場追。 |
| **毒液爆裂** | `1299838` | 坦克消球後的 10 秒可堆疊團傷；運球者同時在外場時優先維持 HOT。 |
| **處斬／冷酷處斬** | `1283594`／`1299296` | 固定組分攤；進分攤前補滿並預鋪。 |
| **恐怖威壓** | `1288635` | P2 持續團傷。 |
| **幽暗炸彈／墓縛** | `1310883`／`1297906`、`1308330` | 炸彈爆炸後目標撿三片靈魂；一路維持 HOT。 |
| **精魂抹除** | `1287722` | P2.5 四批碎片各造成團傷，按四波處理。 |
| **盤繞祭壇褻瀆** | `1298594` | P3 團隊吸收盾與安全地板變化；先鋪團再移動。 |

### 戰鬥循環

P1 是毒液階段：毒球持續造成聚合毒液，固定運球者取得揮發毒液後把球送往坦克；坦克消球會觸發可堆疊的毒液爆裂。期間還會改變安全地板並穿插處斬分攤，轉階段前要清掉剩餘毒球。

P2 改成暗影階段：全團持續承受恐怖威壓與永恆夜幕治療吸收；幽暗炸彈爆炸後會留下墓縛，目標必須撿回三片靈魂並在過程中持續受傷。P2.5 由精魂抹除產生四批靈魂碎片，每批都造成一次團傷。P3 將毒球、運球、毒液爆裂、處斬與暗影吸收盾／點名合併，壓力集中在多種技能同時出現的波次。

3. 即將進處斬／冷酷處斬的固定組。
4. 永恆夜幕吸收盾與正常團血。

## H8 Ula'tek

治療模型：[劇毒 8 王 H 治療分析](../../../首領/劇毒8王_Ulatek/H/治療分析.md)

### 你的工作

- 石化釘刺與毒蛇之咬前先替實際點名者預鋪；不必硬切主責，看到危險血線仍直接補。
