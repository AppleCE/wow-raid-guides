# WoW 團本治療攻略

這是一套給團隊實戰使用的治療資料：先讀首領頁理解「為什麼這裡危險」，再看自己的補職頁，最後把 NS 軸匯入遊戲。

版本：正式服 `12.1.0`。最後整理：`2026-08-24 14:55（Asia/Taipei）`。

## 從這裡開始

1. [每王治療分析](#每王治療分析)：戰鬥流程、正常治療缺口、機制死亡、團減與單點責任。
2. [補師分配](補職攻略/補師分配.md)：依首領分頁，列出主責、備援、交接條件與特殊提示。
3. [整團 NS 軸](整團NS軸/README.md)：實際角色的五補／六補接力；H5 六補為預設、五補為備案。
4. 個人 NS 軸：每個補職資料夾內可直接複製；第三團 `龍餘`、`小印` 使用通用版本。
5. [團隊補招與減傷時間軸](整團時間軸/README.md)：按 H／M 與首領查詢王技能、五／六補、團減及個減。
