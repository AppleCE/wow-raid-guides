## H5 Sszorak

[補師分配](../補師分配/H5_Sszorak.md)｜[治療攻略](../../首領/劇毒5王_Sszorak/H/治療分析.md)

### 先記住你的工作

所有補師都要看團血與危險點名；H5 額外指定放球主責，是因為兩名目標會離團、分方向並可能超出其他補師射程。

- **菈菈跳來跳去**主顧每次兩名毒素湧流／放球者；你是固定機動備援。
- 菈菈被點、被迫留在另一側、超出射程，或兩名放球者分開時，你接其中一人並顧到 `1305963` 結束。
- Arielle 與呆小鄭優先點補帶致殘劈砍的高危目標；你同時幫看第三名危險目標與移動中的放球者。
- 沒有發生交接時仍正常看全團，不需要為搶點名主動離開自己的治療位置。

| **暴怒橫風** | 持續傷害 `1312219`、到期爆炸 `1285616` | 橫風會疊到毒素湧流最後幾跳。先看被點者與帶致殘劈砍者，再處理一般團血。 |
| **肢解／致殘劈砍** | `1285999`／`1285998` | 坦克連招中的正面分攤會留下流血；流血者再中毒素湧流或橫風時是最高危單點。 |
| **暴風** | `1287083` | 可避免的毒。中招者又帶流血或放球時先用化毒袪病（`115450`）處理；多人同時中毒由補薩反應放清毒圖騰。 |
| **黏稠囊腫** | `1287205` | 留給大風階段使用。大風會依序處理四顆囊腫，每次撞球都有一波全團傷害與擊退。 |

### 戰鬥循環

整場會重複三次相同的大循環，王的動作順序是：

1. 王先做**頂尖掠食者／肢解**坦克連招。指定分攤組進正面分傷，之後身上會留下致殘劈砍流血；場上同時持續有背景傷害與需要閃避的暴風。
2. 接著第一次**毒素湧流**點兩人。兩人移動到指定位置，約 10 秒持續掉血，結束時各自造成一波團傷並留下囊腫。
3. 毒素湧流尚未完全結束時，王接著施放**暴怒橫風**。被點者先承受持續傷害，結束時爆炸、擊飛，再依團隊戰術完成對撞；這一段會與前面的流血及毒素湧流重疊。
4. 王再次做一輪坦克連招，接著第二次毒素湧流兩人與第二次暴怒橫風。兩次毒素湧流總共留下四顆囊腫。
5. 王進入**大風／囊腫階段**。團隊依戰術連續處理四顆囊腫；每次撞球都會造成一次全團傷害與擊退，所以是「撞一顆 → 擊退與團傷 → 移動回穩 → 下一顆」共四個波次。
6. 四顆處理完後回到王身邊，重新開始下一個大循環；第三次大風後進入收尾。

同一主階段有兩次毒素湧流，不是只在大風前顧一次；每次的兩名目標約相差 2 秒出現。補僧在主階段看放球交接與三層 DOT，大風階段則連續處理四次擊退團傷。

### 目標優先順序

1. 已交接給你的毒素湧流／放球者。
2. 同時帶致殘劈砍＋毒素湧流／橫風的人。
3. 中暴風又疊其他傷害的人；能解毒就先解。
4. 其他毒素湧流目標與正常團血。

這個順序不是叫你忽略其他人，而是在多個人同時掉血時決定先按誰。

## H6 The Twin Fangs

[補師分配](../補師分配/H6_The_Twin_Fangs.md)｜[治療攻略](../../首領/劇毒6王_The_Twin_Fangs/H/治療分析.md)

### 先記住你的工作

- 全補共同看六輪盤卷膿液；Arielle／呆小鄭優先直補、菈菈預鋪，你在放水與躲波移動時幫看點名者。
- 被點者接著進盛宴、腐蝕球或攪動深淵時，照顧持續到下一次傷害落地。
- 盛宴按固定三組依序進圈，前一組帶易傷不能換組；進圈前補滿自己組。
- 腐蝕球一人一球。用機動治療處理附近低血者，不追離群者破壞站位。

| **盤卷膿液** | 目標 `1290814`、施放 `1290809`、傷害 `1290878` | 約 7–8 人分散放水；移動中優先幫看低血點名者。 |
| **攪動深淵** | `1290956`／`1292806` | 放水後約 8 秒團傷並躲波；天尊導引與玉龍主要覆蓋這段。 |

### 戰鬥循環

每輪先有永恆毒液與有毒氣體的背景傷害，盤卷膿液再點約 7–8 人分散放水；王隨即接攪動深淵，團隊一邊躲波、一邊承受約 8 秒團傷。之後固定三組依序處理貪噬盛宴，吃過的組有易傷不能換進下一圈。輪次之間穿插腐蝕球，一人一顆。流程共六輪，背景毒傷逐輪變重；最後接血雨收尾。

4. 高層永恆毒液下的正常團血。

## H7 The Coiled Altar

[補師分配](../補師分配/H7_The_Coiled_Altar.md)｜[治療攻略](../../首領/劇毒7王_The_Coiled_Altar/H/治療分析.md)

### 先記住你的工作

- Arielle 主顧揮發毒液運球者；運球者同時撞毒液爆裂、處斬或暗影團傷時，你是固定備援。
- 菈菈在運球前預鋪。你以機動性保持外場目標射程，接手後顧到揮發毒液結束。
- P2 改看斬擊、幽暗炸彈、墓縛與永恆夜幕吸收盾；P2.5 四批碎片按四波回補。
- P3 恢復運球並同時混入暗影機制，先找運球重疊者，再處理一般團血。

| --- | ---: | --- |
| **聚合毒液** | `1282408` | P1／P3 毒球脈衝，準備團補。 |
| **揮發毒液** | 光環 `1282419`、傷害 `1282288` | 固定運球者約 5 秒持續掉血；高壓時接 Arielle 的備援。 |
| **毒液爆裂** | `1299838` | 坦克消球後 10 秒可堆疊團傷；與運球重疊時優先外場目標。 |
| **處斬／冷酷處斬** | `1283594`／`1299296` | 固定組分攤，進圈前補滿。 |

| **精魂抹除** | `1287722` | P2.5 四批碎片，每批一次團傷。 |
| **盤繞祭壇褻瀆** | `1298594` | P3 治療吸收盾與安全地板變化，先鋪再移動。 |

### 戰鬥循環

P1 是毒液階段：固定運球者拿揮發毒液送球，坦克消球後觸發可堆疊毒液爆裂；期間穿插安全地板改變與處斬分攤。P2 是暗影階段，恐怖威壓與永恆夜幕持續壓團，幽暗炸彈後的墓縛目標要撿三片靈魂。P2.5 的精魂抹除分四批造成團傷。P3 把毒球、運球、毒液爆裂、處斬與暗影吸收／點名合併，重點是運球者撞上其他傷害時的單點存活。
