# 龍補 H攻略（簡略）

通用版本；第三團 `龍餘` 可直接使用。補招秒數看 [個人 NS 軸](NS軸/H/README.md)，本頁只留補招以外要注意的事。

| 王 | 你要盯誰／做什麼 |
| --- | --- |
| 浪縛單王 | 冰球點名與連吃球者；漩渦前先往下一個集合點移動。 |
| H1 | **精華撕裂（`1287434`）** 出圈前先放回音；不要追到失去大團 30 碼射程。 |
| H2 | 紅側分攤／驅散或綠側踩球前，先站到能看完整半場的位置。 |
| H3 | 三連分攤擊退前先靠近落點；先知階段先鋪尚未清掉霜火的人。 |
| H4 | 暗盾由補聖與神牧一起顧；火怪死亡前先站到下一個集合點。 |
| H5 | 盯 **致殘劈砍（`1285998`）＋毒素湧流（`1306120`／`1312156`）**；橫風前先站到自己半場終點。 |
| H6 | 盛宴前鋪高層 **永恆毒液（`1290480`）＋有毒氣體（`1294976`）** 者；放球前先換位。 |
| H7 | 暗階段鋪幽暗炸彈／墓縛；P3 毒暗重疊時保持大團在 30 碼內。 |
| H8 | 待補。 |

## 補師盯與自保

| 王 | 補師盯／外部 | 本人自保／糖紅 |
| --- | --- | --- |
| H4 | 暗盾由補聖＋神牧顧；你維持大團，盾撞火怪傷害才補時間擴張。 | `02:56` 全團自保；`04:16` 短 CD／第二個個減；`07:11` 全團自保。`01:36` 被點或低血者糖／紅。 |
| H5 | 先鋪致殘劈砍＋毒素湧流雙 debuff；低血才補時間擴張。 | `03:02`、`06:04` 全團自保；被點或低血者糖／紅。 |
| H6 | 先鋪高毒層又將進盛宴／吃球者；低血才補時間擴張。 | `01:57`、`04:47`、`07:36` 全團自保；`06:28` 只交短 CD／第二個個減；`07:54` 低血紅、`08:07` 低血糖。 |
| H7 | 先鋪斬擊、單獨炸彈／墓縛；點名撞毒液大傷才補時間擴張。 | `02:23`、`05:53`、`08:12` 全團自保；P2 單獨點名不固定要求個減。被點低血才糖／紅。 |

共通：`時光倒轉` 等傷害落地再按；`靜滯` 的儲存與釋放是兩個時間點。沒有看到實際 `空間悖論`，就不能假設寧靜或神聖禮頌能移動引導。

詳細流程：[龍補 H攻略（詳細）](H攻略_詳細.md)。
