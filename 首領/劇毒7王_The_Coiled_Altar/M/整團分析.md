# M7 盤蛇祭壇：這團卡在哪裡、我們要先練什麼

> 更新：2026-09-21｜傳奇｜版本 12.1.0.69875
>
> 參考 BabyMonster 9/19 的 **13 把：12 把滅團、1 把過王**。這是外團的當晚紀錄，用來找練習重點，不是我們團的失誤統計。
>
> [完整攻略](完整攻略.md)｜[治療分析](治療分析.md)｜[WCL 原報告](https://www.warcraftlogs.com/reports/R8Tp2AQCnJWhgGHv)

## 先看結論

**先練球的處理，再練「炸彈 → 收魂 → 下一輪分攤」的交接；王盾要有人留爆發、有人等著斷。** 這三件事都在失敗場造成明顯後果。P2 帶鬼也要分開走，不能一起堆到坦克面前。

這份紀錄最常在下面三段結束。不過，**滅團的時間不一定是第一個失誤的時間**：有人可能早就倒了，團隊仍繼續打幾分鐘。

| 滅團時間 | 幾把 | 這段要注意什麼 |
| --- | ---: | --- |
| 01:00–01:59 | 3 | 都出現毒液破裂造成死亡；其中兩把看得到突然多出20層，但有一把在加層前已先死人 |
| 08:00–08:59 | 3 | 原因不同：一把先爆量破裂，另兩把在第二次分攤失敗；其中一把分攤前已雙炸、收魂死人 |
| 03:00–03:59 | 2 | P2 心控、帶鬼與炸彈附近；兩把都有鬼碰撞致死，另有尚未查明的死亡 |

其餘4把分別在04分、05分、09分、10分結束，各1把。完整逐場表放在頁尾，需要追某一把時再展開。

## 1. 球出事時，先改路線，不是先加補招

**發生了什麼：**紀錄5在約01:05，破裂從3層跳到23層，接著開始死人。紀錄6也出現4層跳24層，但它在這之前就已先倒一人，第一個死因還不能確定。

**過王場怎麼通過：**對應第3、4刀清球後都只有5層，沒有突然多出20層，也順利補完這兩輪持續傷害。這不代表每刀都應固定清5顆，而是要避免計畫外的爆量。

**下一把怎麼改：**刀前先把紫球的獨立通道留好，再安排綠球；球仍要能被下一刀清掉。搬球者在出刀前離開正面。下一把先看「有沒有又突然加20層、該清的球有沒有清掉」。目前紀錄不能指出是哪個人撞了哪顆球，不按這份資料點名責怪。

另外，紀錄4、7各有一名非坦被第7、8刀劈死；過王場這兩刀只打到接刀坦。**整理球時也要確認人已退出刀線**，不能只顧球的位置。

## 2. P2 帶鬼要分開，收完魂也不代表安全

**發生了什麼：**紀錄3在約03:28–03:29有兩人死於鬼碰鬼的「惡意共鳴」。其中一人早已收完自己的魂，之後才被共鳴打死，所以這兩死不能都算成沒收魂。紀錄7也有同類死亡。

**過王場怎麼通過：**整場沒有鬼碰撞傷害。第一輪四名炸彈點名各吃一發、各收三片，兩怪也成功拆盾；但仍炸到一名未點名術士，只是被救回。過王不等於每個人都做對。

**下一把怎麼改：**解控後找回自己的鬼，分開帶進預定刀區，轉身讓鬼停住；不要大家把鬼堆成一點。已出共鳴時，先把鬼拉開並急救被追的人。補師要繼續看炸彈／收魂者，不能一爆完就轉走。

## 3. P3 最需要練的是整串交接：炸彈 → 收魂 → 分攤

**發生了什麼：**紀錄11約08:25，兩人各吃到兩發炸彈、墓縛變6層；接著收魂死人，下一次分攤又失敗。紀錄12也出現雙炸死亡和收魂到期。另有一把只吃正常一發，卻一片都沒收，最後到期死亡。

過王場這一輪的順序很清楚：

| 時間 | 做完了什麼 |
| --- | --- |
| 08:20 | 四人被點炸彈 |
| 08:25 | 四人各吃一發，沒有炸到額外的人；兩隻小怪的盾都拆掉 |
| 08:28–08:31 | 四人各收完三片魂，墓縛全部解除 |
| 08:35 | 五個有效目標接到下一次分攤，沒有觸發人數不足的處決 |

**下一把怎麼改：**依[攻略的近遠分流](完整攻略.md)去炸怪：兩圈都罩住怪，但每名玩家都站在另一人的圈外。爆完立刻收魂；如果還沒收完就要接下一圈，立即叫備援，別一個人硬做兩件事。分攤前重新點齊有效人數，確認易傷和免疫可用。

補師要顧到最後一片收完。過王場這輪獵人也曾只剩約5%血，成功是完成機制並獲得急救，並非這段很好補。雙炸也不是一定救不回，但多出的收魂負擔會擠壓下一個工作，應先避免。

不能把所有分攤失敗都怪前面死人：紀錄10也分攤失敗，但當輪誰沒到位、免疫是否失效仍未確定；另有一把即使先倒一人，仍成功接圈。

## 4. 王盾要先打掉，再確實斷法

**發生了什麼：**紀錄4第二次王盾約05:33開始，直到05:48永夜已造成傷害，盾才消失，而且沒有成功打斷，後面直接倒一片。

**過王場怎麼通過：**同一輪在約05:46先破盾，接著成功打斷。兩個動作缺一不可，不能看到盾消失就以為做完了。

**下一把怎麼改：**盾前留能及時生效的輸出；主斷、備斷提前就位，盾破立刻確認已斷。還在收魂或處理小怪的人要有人接工作，不能要求全員同時轉王。

紀錄14則是約08:00先被異常破裂打倒多人，之後永夜才讀完。這把要先修球，不能只怪王盾打太慢。

## 5. 轉 P2 是真正要補的尾傷，王倒下不能停補

同一位龍補在失敗場與過王場，轉場前後差別如下：

| 比較 | 紀錄14：死亡 | 紀錄15：過王 |
| --- | --- | --- |
| 轉場破裂 | 13層 | 12層 |
| 最後一跳破裂後 | 約10%血 | 約67%血 |
| 接到P2第一跳後 | 死亡 | 約61%血 |
| 黑曜鱗片 | 該段沒有覆蓋 | 有覆蓋尾傷與P2第一跳 |

失敗場也有收到大量治療，不能直接判成「補師沒補」；兩把的前置血量、吸收、減傷和層數都有差。

**下一把怎麼改：**最後一刀先整理殘球；補師提前完成移動，保留尾傷的施法與減傷覆蓋。一直補到破裂結束、P2第一跳接完且血量穩定，才轉去處理新工作。

## 6. 中場不是本次主要滅團點，但不能亂掃魂

查到的六把都通過中場，沒有在這段死人，所以目前不能把它列成已證實的主要拓荒牆。

過王場接魂最密集的一段約在06:58–07:03：5秒內有5次全團傷害，易傷升到10層，前面已有靈魂連結支援；之後傷害變疏，團血才恢復。即使單秒只接兩次，連續接仍會刷新易傷，不能當成安全節奏。

**下一把怎麼做：**分區接魂，上一批易傷還在、團血未回穩時，先停非必要的前衝；確認能接下一波再放行。魂已逼近王就要立即攔截，同時喊連接、交生存資源，不能為了等固定秒數而漏魂。10層是這場曾經扛過的結果，不是安全上限。

## 後段還有哪些問題沒解完

紀錄8、12在09分之後仍有爆量破裂、收魂到期等事故，全部保留在下方表格。但這時已有前面的死亡，不能把後面每次倒人都當成新的獨立拓荒牆。球究竟在哪裡碰撞、誰的路線出問題，還需要畫面才能確認。

這份分析能支持前面的練習重點；不能據此決定我們要帶幾補，或直接排出具名免疫、搬球與看護名單。
