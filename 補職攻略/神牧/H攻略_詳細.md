# 神牧 H攻略（詳細）

適用角色：本團 `呆小鄭`。目前完成浪縛單王與 H1–H7，H8 待補。`輝環` 的名稱與排法已依神牧玩家回饋修正。

## 共通手法

- `輝環` 會提供治療增益與 5 發瞬發 `治療禱言`；優先放在 `神化` 持續期間，或 `神聖禮頌` 前後 8 秒內。
- `神聖禮頌` 需要站著引導；只有龍補明確給到 `空間悖論` 時，才可把它當成可移動引導。
- 輝環若因一分鐘冷卻無法貼近下一個神化／禮頌，而當下正好是必要治療缺口，可以單獨使用，不為吃增益延誤致命波次。

## 浪縛單王 Nymrissa Wavecaller

治療模型：[浪縛單王 H 治療分析](../../首領/浪縛單王_Nymrissa_Wavecaller/H/治療分析.md)

一句話：冰球點名與連吃球者先補穩；神聖禮頌放在團隊站定的深淵之雨，不能撞穿越漩渦缺口的移動。

主要軸：`00:12` 起每約 65 秒用輝環周轉；`01:29`、`06:16` 神聖禮頌。禮頌前後盡量吃到輝環 8 秒增益，但移動將到就提前唱完。低血又要連吃球／撞雨的人才給守護聖靈。

## H1 Nek'zali the Soulcoiler

治療模型：[劇毒 1 王 H 治療分析](../../首領/劇毒1王_Nekzali_the_Soulcoiler/H/治療分析.md)

一句話：**精華撕裂（`1287434`）** 出圈前補穩；禮頌完整覆蓋四連或 P2 持續團傷，移動中用輝環與瞬發聖言。

主要禮頌在 `00:36`、`03:08`、`05:23`、`08:39`；輝環約每 60–65 秒使用。P2 低血又要吃下一輪四連者優先快速治療；與四連／底傷重疊才給守護聖靈。漏怪、吃光束與屍體復活歸機制。

## H2 Entombed Sentinels

治療模型：[劇毒 2 王 H 治療分析](../../首領/劇毒2王_Entombed_Sentinels/H/治療分析.md)

一句話：只顧自己半場；紅側先補分攤後與等待驅散者，綠側先補踩毒滴又撞大軟脈衝者。禮頌要避開配對移動。

主要禮頌在 `02:10`、`04:24`、`06:38`；`04:40` 神化接後段高壓。分場時不要因另一側掉血中斷自己半場的主責；配錯四層、漏毒滴與大軟過慢歸機制。

## H3 The Lost Explorers

治療模型：[劇毒 3 王 H 治療分析](../../首領/劇毒3王_The_Lost_Explorers/H/治療分析.md)

一句話：商人顧散射高層；大副在三連分攤前唱完禮頌，擊退開始後改用瞬發；先知階段先顧霜火未清者。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:01`、`00:09`、`00:48` | 輝環 → 神化 → 神聖禮頌 | 前兩次 Nova；禮頌對齊 `00:48`。 |
| `01:02` | 輝環 | 商人階段散射流血；此發因冷卻無法貼近上一個禮頌，屬必要窗口單獨使用。 |
| `02:06`、`02:12` | 輝環 → 神化 | `02:23`、`02:54` Nova 前的聖言周轉。 |
| `03:08`、`03:16` | 神聖禮頌 → 輝環 | 禮頌要在 `03:21` 三連分攤與擊退前唱完；輝環放在禮頌後 8 秒內。 |
| `04:12`、`04:20` | 神化 → 輝環 | `04:24` Nova 與大副階段收尾。 |
| `05:13`、`05:21` | 神聖禮頌 → 輝環 | 先知第一輪霜火點名前預鋪；輝環在禮頌後 8 秒。 |
| `06:20`、`06:26` | 神化 → 輝環 | `06:29` 最後 Nova；不再保資源。 |

操作重點：高層散射、三連分攤標記、霜火未清者是快速治療與守護聖靈的優先目標。`05:27` 若出現 Elemental Explosion 是元素踩錯，不因指定擊殺有人活下來就排成固定禮頌。

## H4 Vashnik the Malignant

治療模型：[劇毒 4 王 H 治療分析](../../首領/劇毒4王_Vashnik_the_Malignant/H/治療分析.md)

一句話：你負責顧 **冥魄感染** 暗盾；看到盾就直接補掉。禮頌要在火怪爆炸前站定，不要排在祭壇切換移動途中。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:12–00:52` | 神化、輝環、神聖禮頌 | 第一輪血暗、Catalyst／Bile 與第一批暗盾。 |
| `02:13–03:16` | 神化、輝環、神聖禮頌 | 第二輪火怪後半接第三輪；禮頌站定後再唱。 |
| `04:28–05:18` | 神化、輝環、神聖禮頌 | 第四輪兩隻火怪與暗盾。 |
| `07:30–07:45` | 神聖禮頌、輝環 | 第六輪 Rush；輝環盡量放禮頌後 8 秒內，但不得晚到錯過火怪死亡。 |

操作重點：暗盾正式名稱為 **冥魄感染**（`1294994`），不是吸取感染。盾目標將同時吃火怪死亡／Catalyst 時，先給守護聖靈再清盾；只有重疊高危才交外部。自保：`02:56`、`07:11` 開漸隱術／絕望禱言；`04:16` 只交第二個減；`01:36` 低血糖／紅。

## H5 Sszorak

治療模型：[劇毒 5 王 H 治療分析](../../首領/劇毒5王_Sszorak/H/治療分析.md)

一句話：`01:37–01:40`、`03:02–03:05` 與補聖一起顧流血＋毒素湧流＋橫風三層 DOT；快速治療與守護聖靈優先給帶致殘劈砍者，不要等到期爆炸才救。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:05` | 輝環＋神化 | 開場肢解與第一輪毒素湧流前的聖言周轉。 |
| `01:04`、`01:08` | 神聖禮頌 → 輝環 | 第一輪橫風結束、團隊站穩後回補；輝環在禮頌後 4 秒。 |
| `02:06`、`02:10` | 神化 → 輝環 | 第一次囊腫後與下一輪肢解。 |
| `03:16`、`03:26` | 輝環、神聖禮頌 | 輝環先補第三輪收尾；禮頌在下一輪移動前唱完。兩者相差 10 秒，這次不硬等增益。 |
| `04:08`、`04:20` | 神化、輝環 | 第二次囊腫後回穩；輝環屬必要窗口單獨使用。 |

操作重點：肢解後高亮致殘劈砍；`01:37`、`03:02` 橫風開始前先找仍帶傷口者，三層 DOT 的 2–3 秒與補聖共同盯。外出放球由補德／補僧跟出，你留主團，不追離群點名。守護聖靈只給該窗口低血或吃到風暴又低血者。正常到期單發不是主要壓力；撞球、彈飛與摔死不靠禮頌補救。自保：`03:02`、`06:04` 開漸隱術／絕望禱言；三層 DOT 低血再補個減／糖紅。

## H6 The Twin Fangs

治療模型：[劇毒 6 王 H 治療分析](../../首領/劇毒6王_The_Twin_Fangs/H/治療分析.md)

一句話：與 Arielle 一起顧高毒層、即將吃盛宴或腐蝕球的人；每次神聖禮頌都在放水分散前站好，最後一發收 `08:07` 後血雨。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:36–00:45` | 輝環 → 神聖禮頌 | 第一輪放水前預鋪；在移動開始前唱。 |
| `01:36–01:50` | 神化 → 輝環 | 第二輪攪動深淵前聖言周轉。 |
| `03:01`、`03:31` | 輝環、神聖禮頌 | 第三輪放水前站定，禮頌接攪動深淵。 |
| `04:03`、`04:40`、`05:09` | 輝環 → 神化 → 輝環 | 第三輪後回穩並準備第四輪。 |
| `06:16–06:19` | 輝環 → 神聖禮頌 | 第五輪放水前完成引導。 |
| `06:53` | 神化 | 第五輪盛宴後回穩。 |
| `07:18`、`08:19` | 輝環、神聖禮頌 | 第六輪預備；最後血雨收尾。 |

操作重點：守護聖靈給高毒層、低血且將進盛宴／吃球的人。沒有龍補，不能假設有空間悖論；放水或躲波開始後不要硬唱禮頌。自保：`01:57`、`04:47`、`07:36` 開漸隱術／絕望禱言；`06:28` 只交第二個減；`07:54` 低血紅、`08:07` 低血糖。

## H7 The Coiled Altar

治療模型：[劇毒 7 王 H 治療分析](../../首領/劇毒7王_The_Coiled_Altar/H/治療分析.md)

一句話：與 Arielle 一起顧斬擊、幽暗炸彈與墓縛；禮頌對齊站位穩定的持續毒液或毒暗重疊，不在處理點名移動時硬唱。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:23`、`01:06` | 輝環＋神化 → 神聖禮頌 | P1 第一、二段連續毒液團傷。 |
| `01:25`、`02:23–02:28` | 輝環；神化＋輝環 | P1 後續波次與進 P2 前回穩。 |
| `03:43–03:45` | 輝環 → 神聖禮頌 | P2 幽暗炸彈／墓縛密集段；先站定再唱。 |
| `04:50` | 輝環＋神化 | P2 收尾與轉入毒暗重疊。 |
| `05:58–06:05` | 輝環 → 神聖禮頌 | P3 第一個明確毒液＋墓縛大缺口。 |
| `07:06–07:08` | 輝環＋神化 | P3 後段連續重疊。 |
| `08:13`、`08:40` | 輝環 → 神聖禮頌 | 擊殺前最後長段團傷；不再保招。 |

操作重點：守護聖靈只給「墓縛／斬擊＋毒液脈衝」或下一跳前仍未補滿的人。單獨墓縛用快速治療／聖言處理；點名正在移動時不要為追他中斷禮頌位置。自保：`02:23`、`05:53`、`08:12` 開漸隱術／絕望禱言；P2 單獨點名先與補聖顧，不固定交個減。
