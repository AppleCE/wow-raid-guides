# 補薩 H攻略（簡略）

通用版本；第三團 `小印` 可直接使用。補招秒數看 [個人 NS 軸](NS軸/H/README.md)，本頁只留補招以外要注意的事。

| 王 | 你要盯誰／外部 | 本人自保／糖紅 |
| --- | --- | --- |
| 浪縛單王 | 冰球點名與連吃球者；靈魂連結只放團隊已集合的位置。 | 自己連吃球又撞雨時開星界轉移。 |
| H1 | **精華撕裂（`1287434`）** 出圈前先補穩；P2 找低血又將吃四連者。 | 自己帶精華撕裂又撞四連／P2 底傷時開星界轉移。 |
| H2 | 只顧自己半場：綠側盯踩毒滴者，紅側盯分攤後與等待驅散者。 | 自己多顆毒滴／高層標記撞分攤時開星界轉移。 |
| H3 | 盯踩箱高層、三連分攤後低血者、霜火未清者。 | 自己被分攤標記／霜火未清接 Nova 時開星界轉移。 |
| H4 | 暗盾由補聖＋神牧顧；你維持大團，盾撞火怪才補外部。 | `02:56`、`07:11` 全團自保；`04:16` 短 CD／第二個減；`01:36` 被點或低血糖／紅。 |
| H5 | 盯 **致殘劈砍（`1285998`）＋毒素湧流（`1306120`／`1312156`）**；低血才補外部。 | `03:02`、`06:04` 全團自保；被點或低血糖／紅。 |
| H6 | 盯高層 **永恆毒液（`1290480`）＋有毒氣體（`1294976`）**又要進盛宴／吃球者。 | `01:57`、`04:47`、`07:36` 全團自保；`06:28` 短 CD／第二個減；`07:54` 低血紅、`08:07` 低血糖。 |
| H7 | 盯 **斬擊（`1299684`）**、**幽暗炸彈（`1310883`）**、**墓縛（`1297906`／`1308330`）**；重疊大傷才補外部。 | `02:23`、`05:53`、`08:12` 全團自保；P2 單點先補師顧；低血糖／紅。 |
| H8 | 待補。 | 待補。 |

共通：`卓越術` 提早覆蓋整段持續傷害；`靈魂連結圖騰` 只放集合點。漏球、摔死、漏分攤與走錯機制不追加固定團招。

詳細流程：[補薩 H攻略（詳細）](H攻略_詳細.md)。
