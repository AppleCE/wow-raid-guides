# 補聖 H攻略（簡略）

本團角色：`Arielle`。補招秒數看 [個人 NS 軸](NS軸/H/README.md)，本頁只留單點、外部與減傷判斷。

| 王 | 你要盯誰／做什麼 |
| --- | --- |
| 浪縛單王 | 冰球點名、連吃球者，以及深淵之雨前仍未滿血的人。 |
| H1 | **精華撕裂（`1287434`）** 出圈前補穩；與四連／P2 底傷重疊才給犧牲祝福。 |
| H2 | 只顧自己半場；紅側優先分攤後、持續掉血與等待驅散者。 |
| H3 | 盯踩箱高層、三連分攤標記、尚未清掉霜火又將吃 Nova 的人。 |
| H4 | 與神牧一起顧 **冥魄感染（`1294994`）**；盾撞火怪死亡時再給外部。 |
| H5 | 與神牧一起顧 **致殘劈砍（`1285998`）**；同時帶毒素湧流者最高優先。 |
| H6 | 與神牧一起顧盛宴前未滿血、高毒層又要吃盛宴／腐蝕球的人。 |
| H7 | 與神牧一起顧斬擊、幽暗炸彈與墓縛；點名撞毒液爆裂時才升級犧牲祝福。 |
| H8 | 待補。 |

共通：`精通光環` 是傷前減傷，不是傷後回補；犧牲祝福只給「單點＋下一個致命技能」的重疊，不對每個普通點名固定交。
