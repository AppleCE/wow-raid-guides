# 補薩 H攻略（簡略）

通用版本；第三團 `小印` 可直接使用。補招秒數看 [個人 NS 軸](NS軸/H/README.md)，本頁只留補招以外要注意的事。

| 王 | 你要盯誰／做什麼 |
| --- | --- |
| 浪縛單王 | 冰球點名與連吃球者；靈魂連結只放團隊已集合的位置。 |
| H1 | **精華撕裂（`1287434`）** 出圈前先補穩；P2 找低血又將吃下一輪四連者。 |
| H2 | 只顧自己半場：綠側盯踩毒滴者，紅側盯分攤後與等待場邊驅散者。 |
| H3 | 盯踩箱高層、三連分攤後低血者、尚未清掉霜火的人。 |
| H4 | 暗盾由補聖與神牧一起顧；你維持大團及火怪死亡後血線。 |
| H5 | 盯同時帶 **致殘劈砍（`1285998`）＋毒素湧流（`1306120`／`1312156`）** 的人。 |
| H6 | 盯高層 **永恆毒液（`1290480`）＋有毒氣體（`1294976`）**、又要吃盛宴／腐蝕球的人。 |
| H7 | 盯 **斬擊（`1299684`）**、**幽暗炸彈（`1310883`）**、**墓縛（`1297906`／`1308330`）**；點名撞毒液團傷才升級外部／個減。 |
| H8 | 待補。 |

共通：`卓越術` 提早覆蓋整段持續傷害；`靈魂連結圖騰` 只放集合點。漏球、摔死、漏分攤與走錯機制不追加固定團招。

詳細流程：[補薩 H攻略（詳細）](H攻略_詳細.md)。
