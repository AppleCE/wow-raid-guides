# WoW 團本治療攻略

這是一套給團隊實戰使用的治療資料：先讀首領頁理解「為什麼這裡危險」，再看自己的補職頁，最後把 NS 軸匯入遊戲。

版本：正式服 `12.1.0`。最後整理：`2026-08-22`。

## 從這裡開始

1. [每王治療分析](#每王治療分析)：戰鬥流程、正常治療缺口、機制死亡、團減與單點責任。
2. [補職攻略](#補職攻略)：同一補職跨王要盯的人、站位、預鋪、移動與外部防禦。
3. [整團 NS 軸](整團NS軸/README.md)：實際角色的五補接力與團減。
4. 個人 NS 軸：每個補職資料夾內可直接複製；第三團 `龍餘`、`小印` 使用通用版本。
5. [團隊補招與減傷時間軸](整團時間軸/README.md)：按 H／M 與首領查詢王技能、五補、團減及個減。

## 證據規則

- 社群攻略負責技能、流程與正確應對；使用當前版本、多語系來源交叉確認。
- Google 團隊文件指定的 WCL 負責本團首領技能秒數；排名 WCL 不能取代它。
- 相同戰術與相近補師配置的過王紀錄負責五補接力骨架；Top WCL 只拿來優化單一專精。
- `observed` 是紀錄實際施放；`draft` 是映射到本團後的安排；計畫時間不冒充實際施放。
- 摔死、撞球、漏圈、漏分攤、吃正面等純機制死亡，不用追加固定補招掩蓋。
