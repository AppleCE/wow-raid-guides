# 神牧 H攻略（詳細）

> 最後更新：2026-08-26（Asia/Taipei）

適用角色：本團 `呆小鄭`。目前完成浪縛單王與 H1–H8。`輝環` 的名稱與排法已依神牧玩家回饋修正。

## 共通手法

- `輝環` 會提供治療增益與 5 發瞬發 `治療禱言`；優先放在 `神化` 持續期間，或 `神聖禮頌` 前後 8 秒內。
- `神聖禮頌` 需要站著引導；只有龍補明確給到 `空間悖論` 時，才可把它當成可移動引導。
- 輝環若因一分鐘冷卻無法貼近下一個神化／禮頌，而當下正好是必要治療缺口，可以單獨使用，不為吃增益延誤致命波次。

主要軸：`00:12` 起每約 65 秒用輝環周轉；`01:29`、`06:16` 神聖禮頌。禮頌前後盡量吃到輝環 8 秒增益，但移動將到就提前唱完。低血又要連吃球／撞雨的人才給守護聖靈。

## H5 Sszorak

治療模型：[劇毒 5 王 H 治療分析](../../首領/劇毒5王_Sszorak/H/治療分析.md)

### 先記住你的工作

- 你與 Arielle 共同優先顧帶致殘劈砍的目標，尤其是再疊毒素湧流或暴怒橫風的人。
- 外出放球由菈菈主顧、豆腐天尊備援；你留主團，不追離群目標。
- 神聖禮頌只能放在團隊站定的回穩段，不能排在橫風擊退或四次撞球移動中。
- 守護聖靈留給三層 DOT 下已低血、下一跳前補不滿的人。

### 你要辨識的技能

| 技能 | ID | 你要做什麼 |
| --- | ---: | --- |
| **毒素湧流** | `1305963`／`1312156`／`1306120` | 幫看帶流血或即將進橫風的目標。 |
| **暴怒橫風** | `1312219`／`1285616` | 與湧流、流血重疊前先直補；擊退時不要硬唱禮頌。 |
| **肢解／致殘劈砍** | `1285999`／`1285998` | 分攤後留下流血；你與補聖共同優先顧。 |
| **暴風** | `1287083` | 中招又疊其他傷害者提高優先級。 |
| **黏稠囊腫** | `1287205` | 大風四顆各自造成團傷與擊退，視為四波。 |

### 戰鬥循環

每個大循環先處理肢解分攤與致殘劈砍，接第一次毒素湧流兩人與暴怒橫風；王再做一次坦克連招、第二次湧流兩人與第二次橫風，留下四顆囊腫。大風階段依序撞四顆，每顆都有團傷與擊退。整套重複三次，第三次大風後收尾。

### 完整時間軸

| ---: | --- | --- |
| `00:00–00:47` | 肢解 → 第一次湧流 → 橫風 | `00:05` 輝環＋神化；先補帶致殘劈砍者。 |
| `01:04–01:45` | 站定回穩 → 第二次湧流與橫風 | `01:04` 禮頌、`01:08` 輝環；`01:37–01:40` 與 Arielle 顧三層 DOT。 |
| `01:51–02:22` | 第一個大風／四顆囊腫 | 四次撞球移動時用瞬發；`02:06` 神化、`02:10` 輝環接回穩。 |
| `02:51–03:26` | 第二循環第一次湧流與橫風 | `03:02–03:05` 再次顧三層 DOT；`03:16` 輝環、`03:26` 禮頌在下一輪移動前唱完。 |
| `03:43–04:40` | 第二次湧流、橫風 → 四顆囊腫 | `04:08` 神化、`04:20` 輝環；擊退期間不硬唱。 |
| `05:09–06:20` | 第三循環兩次湧流與橫風 | 留主團共同顧流血重疊；`06:04` 交漸隱術／絕望禱言。 |
| `06:27–收尾` | 最後大風／四顆囊腫 | 四波逐次回補，不再保聖言與瞬發。 |

### 目標優先順序

1. 致殘劈砍再疊毒素湧流／暴怒橫風的人。
2. 三層 DOT 下需要守護聖靈的人。
3. 中暴風又帶其他 debuff 的人。
4. 分攤組與正常團血。

## H6 The Twin Fangs
