# 龍補 H攻略（簡略）

通用版本；第三團 `龍餘` 可直接使用。補招秒數看 [個人 NS 軸](NS軸/H/README.md)，本頁只留補招以外要注意的事。

| 王 | 你要盯誰／外部 | 本人自保／糖紅 |
| --- | --- | --- |
| 浪縛單王 | 冰球點名與連吃球者；漩渦前先往下一個集合點移動。 | 自己連吃球又撞雨時開黑曜鱗片。 |
| H1 | **精華撕裂（`1287434`）** 出圈前先放回音；不要追到失去大團 30 碼射程。 | 自己帶點名又撞四連／P2 底傷時開黑曜鱗片。 |
| H2 | 紅側分攤／驅散或綠側踩球前，先站到能看完整半場的位置。 | 多顆毒滴／高層標記撞分攤時開黑曜鱗片。 |
| H3 | 三連分攤擊退前先靠近落點；先知階段先鋪尚未清掉霜火的人。 | 被分攤標記／霜火未清接 Nova 時開黑曜鱗片。 |
| H4 | 暗盾由補聖＋神牧顧；你維持大團，盾撞火怪才補時間擴張。 | `02:56`、`07:11` 全團自保；`04:16` 短 CD／第二個減；`01:36` 低血糖／紅。 |
| H5 | 先鋪 **致殘劈砍（`1285998`）＋毒素湧流（`1306120`／`1312156`）**；低血才補時間擴張。 | `03:02`、`06:04` 全團自保；低血糖／紅。 |
| H6 | 盛宴前鋪高層 **永恆毒液（`1290480`）＋有毒氣體（`1294976`）** 者；低血才補時間擴張。 | `01:57`、`04:47`、`07:36` 全團自保；`06:28` 短 CD／第二個減；`07:54` 紅、`08:07` 糖。 |
| H7 | 暗階段鋪斬擊、幽暗炸彈／墓縛；撞毒液大傷才補時間擴張。 | `02:23`、`05:53`、`08:12` 全團自保；P2 單點先鋪；低血糖／紅。 |
| H8 | 待補。 | 待補。 |

共通：`時光倒轉` 等傷害落地再按；`靜滯` 的儲存與釋放是兩個時間點。沒有看到實際 `空間悖論`，就不能假設寧靜或神聖禮頌能移動引導。
