# 補薩 H攻略（詳細）

適用角色：本團 `血薩靈`。目前完成 H3–H5；其他王會依進度追加。

## H3 The Lost Explorers

治療模型：[劇毒 3 王 H 治療分析](../../首領/劇毒3王_The_Lost_Explorers/H/治療分析.md)

一句話：卓越術覆蓋第一組三連分攤，靈魂連結留第二組；先知階段優先驅散／照顧尚未清除霜火齊射的人。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `03:08` | 卓越術 | 大副強化開始，完整覆蓋 `03:21–03:25` 第一組三連分攤。 |
| `03:50` | 靈魂連結圖騰 | `03:53–03:57` 第二組三連分攤。三組人都必須站進圖騰。 |
| `06:27` | 卓越術 | `06:29` 最後 Blink Nova 與收尾背景傷害。 |

操作重點：商人階段用激流與單補顧散射高層，不為 Blast Wave 失誤預留團招。三連分攤前確認圖騰落點是三組都會經過的位置；如果團隊還在被擊退途中，延後到集合點。先知階段霜火未清者優先於一般低血。

## H4 Vashnik the Malignant

治療模型：[劇毒 4 王 H 治療分析](../../首領/劇毒4王_Vashnik_the_Malignant/H/治療分析.md)

一句話：冥魄感染由呆小鄭顧；你維持團血。靈魂連結只放在團隊確實集合、火怪即將死亡的位置。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:40` | 卓越術 | 第一輪血暗的 Catalyst／Bile 與感染後團血。 |
| `01:40` | 靈魂連結圖騰 | 第二輪暗火預備，覆蓋 `01:58–02:16` 的 Catalyst、Bile 與火怪死亡。 |
| `03:42` | 卓越術 | 第三輪第一隻火怪後，延續到第二隻死亡前的回穩。 |
| `04:47` | 靈魂連結圖騰 | 第四輪 Catalyst／Bile 與第一隻火怪。若團隊正在大幅移位，改放集合點。 |
| `06:47` | 卓越術 | 第五輪後半接第六輪暗火，不再保資源。 |

`07:12` 不再排第三次靈魂連結：它距 `04:47` 只有 145 秒，冷卻未轉好。第六輪改由 DK 罩、其他補招與全員剩餘個減接手。

操作重點：暗盾不需要你停下整套團補去搶；只在呆小鄭被迫處理機制、盾目標又將吃火怪死亡時補一個快速單補。吸取感染目標若正離開大團，先用激流維持，不跨場追。

## H5 Sszorak

治療模型：[劇毒 5 王 H 治療分析](../../首領/劇毒5王_Sszorak/H/治療分析.md)

一句話：卓越術覆蓋毒素湧流接暴怒橫風；靈魂連結只放在團隊確實集合的肢解或囊腫回穩位置，不拿來處理摔落。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:42` | 卓越術 | `00:35` 毒素湧流接 `00:44` 暴怒橫風。 |
| `01:00` | 靈魂連結圖騰 | 第一輪回穩與下一組肢解；團隊已分散就改放集合點。 |
| `03:48` | 卓越術 | `03:45` 毒素湧流接 `03:54` 橫風。 |
| `04:15` | 靈魂連結圖騰 | `04:09` 第二次囊腫正常傷害後回穩。 |
| `06:49` | 卓越術 | 第三次囊腫後至 `07:03` 最後分攤，不保資源。 |

操作重點：激流與單補先給致殘劈砍＋毒素湧流、吃到風暴或移動中將離開射程的人。圖騰覆蓋正常橫風／分攤傷害；對撞錯誤、撞球與摔死要修機制，不因該死亡加排團減。

## 個減

- H3：自己被三連分攤標記、散射高層或霜火未清接 Nova 時開星界轉移。
- H4：火怪死亡撞 Catalyst／Bile 時開星界轉移；第六輪 `07:34–07:50` 固定保一層。
- H5：自己帶致殘劈砍＋毒素湧流，或低血進橫風時開星界轉移；囊腫擊退前先補滿自己。
