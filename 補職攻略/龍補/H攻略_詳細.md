# 龍補 H攻略（詳細）

適用範圍：通用龍補攻略，可供第三團 `龍餘` 與其他龍補使用。目前完成 H3–H7，H8 待補；長期延伸到浪縛單王、H 全部與 M 全部。秒數以指定 WCL 為主，王的節奏漂移時跟技能波次。

## H3 The Lost Explorers

治療模型：[劇毒 3 王 H 治療分析](../../首領/劇毒3王_The_Lost_Explorers/H/治療分析.md)

一句話：商人階段先顧散射高層；大副三連分攤前靠近落點，避免擊退後超過 30 碼；先知階段先鋪還帶霜火齊射的人。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:15→00:49` | 靜滯 | `00:48` Blink Nova；釋放前先找散射高層者。 |
| `01:55→02:26` | 靜滯 | `02:23` Nova。`02:13` Blast Wave 必須躲，不為硬吃提前釋放。 |
| `03:18` | 輕風 | `03:21–03:25` 第一組三連分攤。開完後跟著分攤落點移動。 |
| `03:48→04:26` | 靜滯 | `03:53–03:57` 第二組三連分攤接 `04:24` Nova。這輪釋放前要能看到被擊退的人。 |
| `05:31` | 時光倒轉 | 第一輪霜火點名與 `05:40` Nova 的正常失血；元素踩錯爆炸仍歸機制。 |
| `05:43→06:15` | 靜滯 | 第二輪霜火點名與先知後半。 |
| `06:28` | 輕風 | `06:29` 最後 Nova；不再保招。 |

操作重點：三連分攤前先把回音放在標記者／分攤後仍低血者；擊退後不要穿場追單一玩家。霜火點名者清除路線較遠時，出發前先鋪回音。時間擴張只給「散射高層接 Nova」、「三連分攤標記殘血」或「霜火點名接 Nova」這三類高危目標。

## H4 Vashnik the Malignant

治療模型：[劇毒 4 王 H 治療分析](../../首領/劇毒4王_Vashnik_the_Malignant/H/治療分析.md)

一句話：冥魄感染交給呆小鄭處理；你維持全團。每隻火怪死前先站到下一個集合點，傷害落地後再用時光倒轉。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:53→01:18` | 靜滯 | 第一輪血暗後半與第二次 Catalyst／Bile。 |
| `01:41`、`01:50` | 輕風 → 時光倒轉 | 第二輪暗火；輕風先減傷，火怪／Bile 落地後再倒轉。 |
| `03:40→04:00` | 靜滯 | 第三輪兩隻火怪，釋放對齊第二隻死亡＋`04:01` Catalyst。 |
| `04:28` | 輕風 | 第四輪暗火進場，提早覆蓋移動與第一段傷害。 |
| `05:37→05:46` | 靜滯 | 第四輪後半回穩，避免把第五輪前的資源放空。 |
| `06:42` | 時光倒轉 | 第五輪血暗後的正常失血；先等傷害發生。 |
| `07:15`、`07:20→07:38` | 輕風＋靜滯 | 第六輪暗火 Rush；靜滯留給火怪、Bile 與暗盾同段。 |

操作重點：龍補 30 碼是這王最容易出問題的地方。祭壇切換前先站到大團下一個集合點；不要為冥魄感染單點離開全團。若暗盾目標又接火怪死亡，你可給時間擴張，但清盾本身仍由呆小鄭負責。

## H5 Sszorak

治療模型：[劇毒 5 王 H 治療分析](../../首領/劇毒5王_Sszorak/H/治療分析.md)

一句話：優先顧同時帶 **致殘劈砍**（`1285998`）與 **毒素湧流**（`1306120`／`1312156`）的人；每輪橫風前先站到自己半場的移動終點，不要等點名者出 30 碼才追。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:12→00:20` | 靜滯 | 第一組肢解／致殘劈砍後回補。 |
| `00:47` | 時光倒轉 | 第一輪毒素湧流與暴怒橫風已落地的正常失血。 |
| `01:54→02:02` | 靜滯 | 第二輪結束與第一次黏稠囊腫前後。 |
| `03:32→03:37` | 靜滯 | `03:45` 第四輪毒素湧流前快速準備。 |
| `03:54` | 時光倒轉 | 第四輪橫風傷害落地後回補。 |
| `05:23→05:32` | 靜滯 | 第五輪毒素湧流／橫風。 |
| `06:58` | 時光倒轉 | 第三次囊腫後至 `07:03` 最後分攤。 |

操作重點：回音先放在致殘劈砍＋毒素湧流、吃到風暴或即將離開射程的人。本場指定 WCL 沒有施放空間悖論，因此不能假設神聖禮頌或寧靜可在橫風中移動引導。黏稠囊腫的正常爆炸可補；撞球、彈飛與摔死不追加固定大招。

## H6 The Twin Fangs

治療模型：[劇毒 6 王 H 治療分析](../../首領/劇毒6王_The_Twin_Fangs/H/治療分析.md)

一句話：優先找高層永恆毒液＋有毒氣體、又即將吃盛宴的人；盛宴前先補滿，腐蝕球重複命中先判機制。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:41→00:46`、`00:55` | 靜滯 → 時光倒轉 | 第一輪攪動深淵接貪噬盛宴。 |
| `02:16→02:21` | 靜滯 | 第二輪盛宴；之後保持大團在 30 碼內接血雨。 |
| `03:42`、`03:45→03:49` | 時光倒轉＋靜滯 | 攪動深淵、盛宴與腐蝕球連續發生。 |
| `05:14→05:19` | 靜滯 | 第二次血雨前後；不要提前放在低壓背景毒傷。 |
| `06:36`、`06:52→07:07` | 時光倒轉＋靜滯 | 後段攪動深淵、盛宴與腐蝕球。 |

操作重點：高毒層者要吃盛宴前先鋪回音；放球移動前先站到下一個集合點。正常盛宴／血雨是治療責任，漏球與同一人重複吃球不追加固定大招。

## H7 The Coiled Altar

一句話：P1 先鋪斬擊＋毒液團傷目標；P2 先顧幽暗炸彈／墓縛；P3 保持大團在 30 碼內，靜滯留給毒暗重疊。

| 時間 | 操作 | 這招在補什麼 |
| ---: | --- | --- |
| `00:25→00:37` | 靜滯 | P1 第一段連續毒液團傷。 |
| `01:55`、`01:59→02:19` | 時光倒轉＋靜滯 | P1 後段與最後一輪毒液爆裂。 |
| `03:41→03:59` | 靜滯 | P2 幽暗炸彈／墓縛連續點名。 |
| `05:17→05:34` | 靜滯 | P3 第一輪毒暗重疊。 |
| `05:55` | 輕風 | P3 中段處斬／凋零撕裂附近壓力。 |
| `06:52→07:24`、`07:25` | 靜滯 → 時光倒轉 | P3 後段毒液、墓縛與凋零撕裂連續重疊。 |

操作重點：幽暗炸彈／墓縛點名先給回音；P3 同時吃毒液脈衝與墓縛者可升級時間擴張。墓縛處理失敗與報復惡意仍屬機制後果，不要為追錯位者失去全團射程。

## 個減

- H3：自己被三連分攤標記、散射高層接 Nova、霜火未清接 Nova時開黑曜鱗片。
- H4：第二、三、四、六輪火怪死亡撞 Catalyst／Bile 時開黑曜鱗片；第六輪不保第二層。
- H5：自己同時帶致殘劈砍＋毒素湧流，或低血進入暴怒橫風時開黑曜鱗片；治療石／紅水留補招覆蓋外的空窗。
- H6：自己高層永恆毒液接盛宴／腐蝕球，或低血進血雨時開黑曜鱗片。
- H7：自己被幽暗炸彈／墓縛點名又撞毒液脈衝，或 P3 連續重疊時開黑曜鱗片。
