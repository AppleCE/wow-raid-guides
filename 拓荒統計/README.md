## 讀法

- 排名分段依 raider.io 世界進度排名切，區間互斥（前 50、51–100、101–200、201–400、401–500）。
- M1、M3 與浪縛單王只顯示世界過王團數，不再納入把數、裝等、區間或逐公會表。其他王超過 500 團後自動套用相同規則。
- 裝等＝首殺陣容的平均裝等，只統計仍在詳細追蹤且有公開陣容的首領。
- 首殺先後分組依仍在詳細追蹤首領的實際擊殺時間排序；「最早 1–25 個首殺公會」就是最早打掉該王的 25 個公會，與公會整體世界排名無關。
- 把數＝擊殺前所有 `ENCOUNTER_START` 次數；擊殺沒有上傳 log 的公會 pull 為 0，已排除。
- 「還在打」＝前 500 內尚未擊殺但已開始拉的公會，列平均把數與最佳％中位數。
- WCL 進度 API 只在競速期間開放；若某天回空，本頁保留前一天內容。
- 把數來源：仍在詳細追蹤的首領以 WCL 進度榜為主；WCL 對不到或擊殺沒上傳 WCL 的公會，以 raider.io Live Tracking 補充。
