## 共通原則

- `卓越術` 要提早開，讓完整持續時間覆蓋連續團傷，不等全團殘血才按。
- `靈魂連結圖騰` 只在隊伍確實集合時有效；分邊、分散或移動出去時，時間到了也不要原地空放。
- 團隊分散時，優先盯帶兩個 debuff、分攤後低血、或正在離開治療射程的人。
- H4 暗盾交給補聖與神牧一起顧；補薩維持其他人的團血。

一句話重點：先顧冰球點名、連吃球與雨後仍低血的人；漩渦移動前先確認下一個集合點，靈魂連結不能丟在團隊即將離開的位置。

| 時間 | 排定技能 | 處理什麼 |
| ---: | --- | --- |
| 00:49 | 療癒之潮圖騰 | 第二輪深淵之雨與雨後持續傷害。 |
| 02:37 | 靈魂連結圖騰 | 中段深淵之雨；確認大團已穿過漩渦缺口並集合。 |
| 05:07 | 卓越術 | 後段深淵之雨與連續團傷。 |
| 06:57 | 靈魂連結圖騰 | 收尾深淵之雨；不再保招。 |

要盯：冰球點名者、連吃第二顆球的人與雨後仍低血者。漏球爆炸、小怪進泡泡、走錯缺口或被擊退出場先歸類為機制問題。

## H1 Nek'zali the Soulcoiler

一句話重點：**精華撕裂（debuff `1287434`）** 目標往場邊前先用激流／單補拉到安全血線；他出射程後不要追到丟掉大團。P2 同一人若還低血又要吃下一次團傷，要求個減／治療石。

| 時間 | 排定技能 | 處理什麼 |
| ---: | --- | --- |
| 01:10 | 卓越術 | P1 四連團傷／小怪死亡造成的持續團血缺口。提早開，不要只補最後一下。 |
| 01:43 | 靈魂連結圖騰 | 團隊集合且低血差大的窗口；若當時正在分散放地板，延後到集合點。 |
| 06:10 | 靈魂連結圖騰 | P2 持續全團傷害的晚段救命層；確認大團真的站在圖騰內。 |
| 06:16 | 卓越術 | 接在圖騰後持續回補，不讓資源只集中在第一個尖峰。 |

要盯：**精華撕裂（`1287434`）**、剛吃完小怪死亡傷害的人、P2 低血且下一次四連傷害將到的人。小怪進井、吃光束或屍體沒燒掉屬機制錯誤，不用固定補招替它兜底。

## H2 Entombed Sentinels

一句話重點：紅側 **不穩定的瘴氣（debuff `1288260`）** 分攤後，先找帶 **黏附黑暗（debuff `1288297`）** 與等待驅散的 **荒疫之血（debuff `1284483`）**；綠側則先顧剛踩毒滴又準備轉階段的人，不要隔場追血。

| 時間 | 排定技能 | 處理什麼 |
| ---: | --- | --- |
| 01:16 | 卓越術 | 第一輪大軟／紅側分攤與標記底傷。依分邊覆蓋自己所在半場。 |
| 03:53 | 靈魂連結圖騰 | 紅側集合分攤或該側多人低血；圖騰不能跨 40 碼同時照顧兩側。 |
| 04:35 | 療癒之潮圖騰 | 中後段轉階段與兩側持續傷害接力。 |

要盯：綠側踩劇毒液滴後的持續傷害（傷害 `1284451`）、紅側 **不穩定的瘴氣（`1288260`）**、分攤後的 **黏附黑暗（debuff `1288297`）**、等待驅散的 **荒疫之血（`1284483`）**。若你不在紅側，`03:53` 必須改成自己半場實際集合窗口，不可照秒數把圖騰放在空地。

## H3 The Lost Explorers

一句話重點：商人階段先顧踩箱後高層 **散射（debuff／傷害 `1308853`）**；先知階段先刷滿還帶 **霜火齊射（火 debuff `1295893`／冰 debuff `1295985`）** 的人；大副三連分攤被擊退後，優先補落在外圍或下一次分攤前仍低血的人。

Google 指定軸：[WCL `gaWNXzLDjb7n6v1T` fight 47](https://tw.warcraftlogs.com/reports/gaWNXzLDjb7n6v1T?fight=47&type=summary)，6:45；餵魚順序 `商人 → 大副 → 先知`。

| 時間 | 排定技能 | 處理什麼 |
| ---: | --- | --- |
| 03:08 | 卓越術 | 03:06 餵大副後的團傷，接 03:21 第一組三連分攤。 |
| 03:50 | 靈魂連結圖騰 | 03:53 第二組三連分攤；分攤組必須站進圖騰。 |
| 06:27 | 卓越術 | 06:29 最後一輪距離團傷與收尾底壓，不再保招。 |

要盯：三連分攤標記、踩箱後的 **散射（debuff／傷害 `1308853`）**、尚未清除的 **霜火齊射（火 `1295893`／冰 `1295985`）**。`Blast Wave` 沒跳過、空分攤與元素踩錯是機制問題；靈魂連結只能救正常分攤，不能把錯誤打法常態化。

## H4 Vashnik the Malignant

一句話重點：暗盾交給補聖與神牧一起顧；補薩維持其他人的團血。帶 **吸取感染（debuff `1295224`）** 的人若又要進下一輪火怪爆炸，提前補滿並提醒個減。

祭壇順序：`血+暗 → 暗+火 → 血+火 → 暗+火 → 血+暗 → 暗+火`。

| 時間 | 排定技能 | 處理什麼 |
| ---: | --- | --- |
| 00:40 | 卓越術 | 第一輪血暗的感染與持續團傷。暗盾由指定單點補師處理，補薩維持其他人的血線。 |
| 01:40 | 靈魂連結圖騰 | 第二輪暗火；團隊集合處理火怪與分攤時使用。 |
| 03:42 | 卓越術 | 第三輪火怪死亡與後半持續傷害。 |
| 04:47 | 靈魂連結圖騰 | 第四輪火怪／分攤重疊；確認不是正在大幅移位。 |

## H6 The Twin Fangs（週末暫定）

一句話重點：優先找同時帶高層 **永恆毒液（debuff `1290480`）＋有毒氣體（debuff `1294976`）**、又即將吃盛宴的人，先補滿再處理腐蝕球；重複中球先判機制，只有正常高毒層進盛宴才升級成外部／個減。

英雄 Top 補薩樣本 `Katieey` 的實際主要技能為：卓越術 `00:53／03:55／07:06`，靈魂連結 `02:13／06:44`。以下依 8:10 機制模型解讀：

| 時間 | 技能 | 機制錨點 |
| ---: | --- | --- |
| 00:53 | 卓越術 | 00:52 攪動深淵，延續到 01:08 貪噬盛宴。 |
| 02:13 | 靈魂連結圖騰 | 02:15 貪噬盛宴 #2；盛宴前先把團血補滿。 |
| 03:55 | 卓越術 | 03:57 貪噬盛宴 #3，之後接 04:12 腐蝕球。 |
| 06:44 | 靈魂連結圖騰 | 06:47 貪噬盛宴 #5；後段毒性底傷較高。 |
| 07:06 | 卓越術 | 後段接力與擊殺前資源；若本團時間較慢，延後覆蓋 07:39→07:54 最後盛宴鏈。 |

最高危窗口是 `02:33 血雨 #1`、`05:25 血雨 #2`、`08:07 血雨 #3`。若團隊減傷沒有覆蓋，療癒之潮或其他主團補優先放血雨；不要為單純背景毒傷提前浪費。腐蝕球重複命中是機制問題，但中球者帶高層毒傷時要立刻單補並要求個減。

## 來源與可信度

正文採固定三層框架，不以單一攻略或單一高 HPS 玩家直接下結論：

1. **社群攻略定義機制與正常應對**：以 [Raidstrats H1](https://raidstrats.gg/guides/nek-zali-the-soulcoiler/heroic)、[H2](https://raidstrats.gg/guides/entombed-sentinels/heroic)、[H3](https://raidstrats.gg/guides/the-lost-explorers/heroic)、[H4](https://raidstrats.gg/guides/vashnik-the-malignant/heroic)、[H5](https://raidstrats.gg/guides/sszorak/heroic)、[H6](https://raidstrats.gg/guides/the-twin-fangs/heroic)，再與 [NGA 分享的 KDocs 摘要](../cooldown_plans/venomous_abyss_kdocs_guide_reference.md)交叉。
2. **WCL 定義實際波次、戰術與開招**：H3 使用 [指定 6:45 擊殺](https://tw.warcraftlogs.com/reports/gaWNXzLDjb7n6v1T?fight=47&type=summary)，H4 使用 [指定祭壇戰術](https://www.warcraftlogs.com/reports/aNHzr2TcXKdVQZmP?fight=35&type=summary)，H5 使用 [指定 7:08 擊殺](https://tw.warcraftlogs.com/reports/3AGyf4Ya7BLvZtPH?fight=59&type=summary)，H6 使用 [補薩樣本](https://www.warcraftlogs.com/reports/R3pZkV98zhJyaHNw?fight=14&type=casts)。
3. **本團草案決定 Arissa 要做什麼**：H1–H5 依二團現有補軸錯開；H6 尚無本團 WCL，所以明標「週末暫定」。收到本團紀錄後，以同戰術技能 occurrence 校時，不直接搬別團秒數。

資料狀態：H1–H2 為社群機制加近似配置 WCL 草案；H3–H5 已有指定戰術 WCL；H6 為近兩週英雄 WCL observed，待本團紀錄定稿。
