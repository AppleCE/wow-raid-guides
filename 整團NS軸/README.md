# 整團 NS 軸

這裡保存 RL 核准後、後續實戰要使用的整團五補或六補治療排招；各補職只看自己開招的版本，仍放在各補職的 `NS軸` 資料夾。NS 只放治療技能，戰士、DK、DH 團隊生存招與個減／糖紅另看 [RL 整團時間軸](../整團時間軸/README.md)。

> 團隊規則：H1、H2 可保留一團／二團分團版本；**H3 起不再分團，只維護「本團」完整補軸**。本團五補為 Arielle／菈菈跳來跳去／呆小鄭／豆腐天尊／Raitoningu；六補加入血薩靈。H5–H7 目前以六補為預設；新增第六補不移動原五補落點。

後續檔案依照以下順序整理：

```text
整團NS軸/
├─ 一團/（H1–H2）
│  ├─ N/
│  └─ H/
├─ 二團/（H1–H2）
│  ├─ N/
│  └─ H/
└─ 本團/（H3 起）
   ├─ H/
   └─ M/
```

每個難度底下以副本與王序命名，例如：

- `浪縛單王.txt`
- `劇毒1王.txt`
- `劇毒2王.txt`

每份檔案保留完整 NSRT 標頭、名單與所有補師的排招，可以直接複製匯入；不混入戰士、DK、DH 或純文字自保提醒。RL 軸首次核准後，整團 NS 與個人 NS 一起建立；後續實戰微調時，兩層 NS 仍要彼此對齊，但不需回寫 RL 軸。
