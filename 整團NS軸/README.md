# 整團 NS 軸

這裡保存整團五補或六補的完整排招；各補職只看自己開招的版本，仍放在各補職的 `NS軸` 資料夾。

> 團隊規則：H1、H2 可保留一團／二團分團版本；**H3 起不再分團，只維護「本團」完整補軸**。既有 H3–H5 二團檔案已停用，只保留追溯，等待本團補師名單後重排。

後續檔案依照以下順序整理：

```text
整團NS軸/
├─ 一團/（H1–H2）
│  ├─ N/
│  └─ H/
├─ 二團/（H1–H2）
│  ├─ N/
│  └─ H/
└─ 本團/（H3 起）
   ├─ H/
   └─ M/
```

每個難度底下以副本與王序命名，例如：

- `浪縛單王.txt`
- `劇毒1王.txt`
- `劇毒2王.txt`

每份檔案保留完整 NSRT 標頭、名單與所有補師的排招，可以直接複製匯入。
